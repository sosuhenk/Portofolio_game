# Folio 2019

## Persiapan
Unduh [Node.js](https://nodejs.org/en/download/).
Jalankan perintah berikut:

``` bash
# Pasang dependensi
npm install

# Jalankan di localhost:1234
npm run dev

# Build untuk produksi di folder dist/
npm run build
```

## Ganti nama / font 3D
Huruf 3D "RAY JOSEPH" dan "KREATIF DEV" dibuat otomatis dari font Anton.
Kalau font diganti, jalankan lagi skrip konversinya:

``` bash
node scripts/convertFont.mjs
```
